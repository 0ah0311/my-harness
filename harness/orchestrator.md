# 오케스트레이터 규칙

## CLAUDE.md 구조 순서

에이전트는 CLAUDE.md를 아래 순서로 읽는다.

1. 트리거 — 어떤 문장이 하네스를 시작하는가
2. 단계·파일명 — 어떤 순서로 무엇을 만드는가
3. 게이트 조건 — 각 단계의 통과 기준은 무엇인가
4. 편집 권한 — 어느 폴더를 읽고 쓸 수 있는가
5. 어기면 안 되는 것 — 어떤 조건이 걸리면 반드시 멈추는가

## 불확실 상황 기본 행동

파일 없음·MCP 오류·모호한 지시 등 판단이 어려운 상황에서:
- 추측해서 진행 금지
- 멈추고 사람에게 한 줄 질문 후 대기

## 파일 구조

- 규칙 SSOT: `CLAUDE.md` 단일 파일
- 에이전트별 별도 지시 파일 없음
- 모든 에이전트는 실행 전 CLAUDE.md를 읽는다

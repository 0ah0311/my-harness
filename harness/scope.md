# 하네스 자동화 범위

| 단계 | 에이전트 역할 | 비고 |
|---|---|---|
| 1. uibowl 레퍼런스 수집 | 직접 실행 | uibowl MCP 직접 호출 |
| 2. 분석 및 반영 포인트 추출 | 직접 실행 | |

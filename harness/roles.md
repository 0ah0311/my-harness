# 역할 규칙

## 에이전트별 편집 권한

| 에이전트 | 쓰기 가능 폴더 | 읽기 전용 |
|---|---|---|
| `collect` | `output/` | `docs/` |
| `analyze` | `output/` | `docs/` |
| `spec` | `output/`, `instructions/` | `docs/` |
| `validate` | `output/` | `docs/`, `output/03-spec.md` |
| 오케스트레이터 | 없음 (쓰기 금지) | 전체 |

## 판정자

별도 판정 에이전트 없음.
오케스트레이터가 각 단계 완료 후 `gates.md` 조건을 직접 검사한다.

## 자연어 트리거

| 트리거 문장 | 동작 |
|---|---|
| `"허들링 레퍼런스 수집 시작해줘"` | collect부터 전체 순서 실행 |
| `"N단계부터 다시 시작해줘"` | N단계 output 파일 삭제 → 해당 에이전트 재실행 |

## 중간 보고

- 각 단계 완료 시 한 줄 요약을 채팅에 출력
- 사람 승인 지점(5단계) 외에는 자동 연속 실행
- 게이트 실패 시 실패 원인 한 줄 출력 후 중단

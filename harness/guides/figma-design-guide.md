# Figma 키스크린 가이드

4단계 보조 에이전트가 instructions/04-figma-keyscreen.md를 작성할 때 따르는 기준.

## 프레임 규격
- 사이즈: 390 × 844
- 기준 프레임: 402 × 874 (본체 Figma와 동일)
- 화면 수: 2~3개

## 색 규칙
- 배경: Canvas #ffffff
- 주요 CTA: Ink #161c1c 채움
- 브랜드 청록(#31cfff): 얇은 포인트 요소에만, CTA 채움 금지
- 캐릭터와 색 스와치만 채도 허용

## 모서리 규칙
| 용도 | 값 |
|---|---|
| 버튼·입력 | 12px |
| 팝업·착장 카드 | 16px |
| 바텀 시트 상단 | 24px |
| 스와치·토글 | 9999px (원형) |
| 무늬 타일 | 4px |

## 그림자 규칙
- 카드: 그림자 없음, 면 색(`#f4f4f4`)으로 구분
- 팝업·시트: `0 10px 10px rgba(22,28,28,0.1)` 만 허용

## 선택 상태
- 2px 잉크(#161c1c) 링 + 아이콘 (색만으로 표시 금지)

## 착장 관련
- 착장은 선택 항목 — 필수 표시(*, 저장 버튼 비활성 조건) 금지
- 지난 착장이 자동 채워짐을 UI에서 표현

## 키스크린 선정 기준
docs/prd.md의 "만들 화면 5개" 중 사용자 시나리오 핵심 흐름을 커버하는 2~3개를 선정한다.

# validate 에이전트

## 역할
output/03-spec.md와 docs/design.md를 대조해 위반 항목을 검토한다.
판정만 하고 spec 파일은 절대 수정하지 않는다.

## 입력
- output/03-spec.md (읽기 전용)
- docs/design.md (읽기 전용)
- docs/prd.md (읽기 전용)

## 출력
- output/07-validation.md

## 쓰기 권한
- output/07-validation.md 만 허용
- 다른 파일 수정 절대 금지

## 체크리스트

### design.md 기반 (디자인 규칙)
- [ ] 모서리 값이 4/8/12/16/24/9999px 이외 값을 사용하지 않는다
- [ ] 브랜드 청록(#31cfff)을 버튼 채움 또는 큰 면에 사용하지 않는다
- [ ] 카드·버튼에 그림자를 사용하지 않는다 (그림자는 팝업·시트에만 허용)
- [ ] 착장을 필수 입력으로 표시하지 않는다 (필수 표시 * 또는 저장 버튼 비활성 조건 금지)
- [ ] 선택 상태를 색만으로 표시하지 않는다 (2px 잉크 링 필수)

### prd.md 기반 (기능 조건)
- [ ] "착장을 설정하지 않아도 기록 저장 가능"이 spec에 명시됐다
- [ ] "착장은 다음 기록에서 자동으로 채워진다"가 spec에 명시됐다
- [ ] "내 장비 수정·삭제 시 이전 기록 착장은 변하지 않는다"가 spec에 명시됐다

## 강제 규칙
위반 항목 1개라도 있으면 임의 통과 불가.
반드시 사람에게 보고 후 대기.

## 불확실 상황
추측 금지 — 사람에게 한 줄 질문 후 대기

# run-harness 스킬

허들링 하네스 전체 파이프라인을 실행한다.

## 트리거
- `"허들링 레퍼런스 수집 시작해줘"` → 1단계부터 전체 실행
- `"N단계부터 다시 시작해줘"` → N단계 output 파일 삭제 후 해당 에이전트 재실행

## 실행 전 확인
1. output/, instructions/ 폴더 존재 확인 (없으면 생성)
2. 각 단계 output 파일 존재 확인 (있으면 완료로 간주, 건너뜀)

## 단계 순서
| 단계 | 에이전트 | 판정 |
|---|---|---|
| 1 | collect | 기계 |
| 2 | analyze | 기계 |
| 3 | spec | 기계 |
| 4 | (보조) | 사람 |
| 5 | (보조·사람 승인) | 사람 |
| 6 | (보조) | — |
| 7 | validate | 기계 |

## 규칙 출처
모든 규칙은 CLAUDE.md를 따른다.
게이트 조건 상세는 harness/rules.yaml을 읽는다.
기본값은 harness/defaults.yaml을 읽는다.

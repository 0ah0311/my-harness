## 공통 패턴 요약

- **기록 조회**: 날짜 피커(캘린더/드롭다운)로 기간 선택 → 요약 지표 카드(숫자 강조) → 차트/테이블 상세 순서가 공통
- **지표 표시**: 현재값과 목표·권장값을 한 줄에 병치해 즉시 비교 가능하게 함
- **공유/내보내기**: 스코어·기록 화면에서 공유 버튼을 하단에 고정 배치
- **아이템 상세(착장)**: 이미지 캐러셀 최상단 → 상태/브랜드 → 가격 → 바텀 CTA 구조 반복

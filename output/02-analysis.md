# 레퍼런스 분석

## 분석 요약

레퍼런스 5건(앳플리, 워크온, 달다방, 카카오골프예약, 차란)을 SWIMMILE 오늘의 물옷 기능 맥락에서 분석했다. SWIMMILE의 핵심 목표는 기록을 무겁게 하지 않으면서 "오늘의 나"를 남기는 개인화 레이어다. 레퍼런스는 세 군집으로 나뉜다.

- **기록 조회 군**: 앳플리, 워크온, 달다방 — 날짜 기반 조회·요약 지표·시각화 패턴 제공
- **세션 결과 카드 군**: 카카오골프예약 — 날짜·참가자 헤더 + 항목별 상세 테이블 + 하단 고정 공유
- **아이템 상세 군**: 차란 — 이미지 캐러셀 + 상태 뱃지 + 바텀 CTA 구조

SWIMMILE 물옷 5개 화면(기록 작성·착장 선택 시트·옵션 편집·내 장비 목록·기록 상세 카드) 각각에 대응하는 패턴을 레퍼런스에서 추출했다.

## 레퍼런스별 핵심 관찰

| # | 앱 | 화면 | 관찰 |
|---|---|---|---|
| 1 | 앳플리 | 운동기록 조회 | 캘린더 날짜 선택이 최상단에 위치하고, 날짜 선택 즉시 아래 요약 카드가 갱신됨. 이 패턴은 "지난번 착장 자동 채우기" 시나리오와 유사 — 기존 값이 이미 표시된 상태에서 사용자가 변경 여부만 결정 |
| 2 | 워크온 | 건강 지표 항목 | 아이콘 + 항목명 + 현재값 + 권장값을 한 행에 배치. 스캔 속도 극대화. 내 장비 목록에서 착장 이름·미리보기 섬네일·색 정보를 한 행으로 표시하는 데 직접 적용 가능 |
| 3 | 달다방 | 통계 주기 | 숫자 강조 카드 + 라인 그래프 + 위험 구간 강조점. 기록 상세 캐릭터 카드에서 "그날의 착장"을 숫자 요약 옆에 카드 단위로 배치하는 레이아웃 참고 |
| 4 | 카카오골프예약 | 스코어카드 확인 | 날짜·코스·참가자 정보 헤더가 맥락을 즉시 전달. 공유 버튼이 하단 고정. 기록 상세에서 날짜·수영장명 헤더 + 착장 카드 + 하단 공유(미래 확장 여지) 구조에 대응 |
| 5 | 차란 | 상품 상세 | 이미지 캐러셀 최상단 → 상태 뱃지(Very-good) → 브랜드·상품명 → 가격 → 바텀 CTA 2버튼. 옵션 편집 화면에서 캐릭터 미리보기 최상단 고정 + 옵션 선택 영역 하단 배치 + 적용 버튼 바텀 고정 패턴에 직접 대응 |

| 4 | **기록 상세 캐릭터 카드는 날짜·수영장 헤더 바로 아래 카드 블록으로 배치** — 맥락(날짜·세션 정보)을 먼저 전달하고 착장 카드가 이어지는 구조 | 카카오골프예약 헤더 + 스코어 구조 / 달다방 숫자 카드 | 기록 상세 | 높음 |
| 5 | **옵션 편집 화면의 "적용" CTA는 하단 고정** — 미리보기를 보며 옵션을 고른 뒤 손을 내리면 CTA가 닿는 엄지 존에 위치 | 차란 바텀 CTA 고정 | 옵션 편집 | 높음 |
| 6 | **내 장비 목록 빈 상태(엠티뷰)에서는 "새로 만들기" 단일 CTA만 노출** — 항목이 없을 때 목록 구조 대신 안내 문구 + 단일 버튼으로 인지 부담 제거 | 워크온 탭 구조(항목 없음 처리) | 내 장비 목록 | 중간 |
| 7 | **착장 선택 시트에서 "이번만 사용 / 내 장비에 저장" 토글을 마지막 단계에 배치** — 편집 과정에서 저장 결정을 강요하지 않고 완성 직전에 한 번 선택하게 함 | 달다방 위험 구간 강조(경고는 마지막에) | 착장 선택 시트 / 옵션 편집 | 중간 |

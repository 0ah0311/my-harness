## 화면별 상세

### 1. 기록 작성 — 수영 착장 영역

**목적**: 기록 저장 흐름을 방해하지 않으면서 착장을 한 번의 탭으로 설정하거나 건너뛸 수 있게 한다.

**레퍼런스 반영 포인트**:
- 앳플리 패턴: 지난번 착장이 기본값으로 이미 채워진 상태로 화면이 열린다. 변경 의사가 없으면 추가 조작 0.
- 착장 영역은 기록 작성 폼 안의 하나의 섹션이며, 필수 입력 표시(`*`) 없음.

**레이아웃** (390×844 기준, 해당 섹션 영역):
```
┌──────────────────────────────────────┐
│  수영 착장                    [변경]  │  ← 섹션 라벨(body-sm 700) + button-underline
│ ┌────────────────────────────────┐   │
│ │                                │   │
│ │       [캐릭터 중앙 배치]       │   │  ← OutfitCard (354×208, colors.subtle 채움)
│ │                                │   │
│ └────────────────────────────────┘   │
└──────────────────────────────────────┘
```

**주요 흐름**:
1. 화면 진입 시 이전 기록의 착장 값이 OutfitCard에 자동 채워짐.
2. 착장이 없는 최초 진입 시 기본 착장(무색·기본 실루엣) 캐릭터 표시.
3. OutfitCard 탭 or "변경" 탭 → 착장 선택 시트(화면 2) 열림.
4. 착장 미설정 상태로 "저장하기" 탭 가능 — 착장은 저장 버튼 활성 조건에 포함하지 않음.

**컴포넌트**:
- `OutfitCard`: colors.subtle 채움, rounded.xl, 354×208, 캐릭터 중앙 배치, 탭 가능
- `button-underline` "변경": caption-lg, 터치 영역 최소 44px

**예외 상태**:
- 착장 미설정: 기본 착장 캐릭터(무채색) 표시. "변경" 라벨 대신 "설정" 라벨 노출.
- 네트워크 오류로 착장 로드 실패: 기본 착장으로 폴백, 재시도 없이 조용히 처리.

### 2. 착장 선택 시트

**목적**: 내 장비 목록에서 빠르게 고르거나, 새로 만들기로 옵션 편집 화면으로 넘어간다.

**레퍼런스 반영 포인트**:
- 워크온 행 레이아웃: 캐릭터 썸네일 + 이름 + 색 스와치 3요소를 한 행에 배치해 스캔 부담 최소화.
- 달다방 패턴(저장 결정 시점): "이번만 사용 / 내 장비에 저장" 결정은 이 시트가 아닌 옵션 편집 마지막 단계에서.

**레이아웃** (바텀 시트, 상단 rounded.2xl):
```
┌──────────────────────────────────────┐
│              ── (핸들 바)            │
│  착장 선택                           │  ← title-lg
│  [새로 만들기]                       │  ← button-secondary 전체 너비
│ ─────────────────────────────────── │
│  내 장비                             │  ← 섹션 라벨 body-sm 700
│ ┌──────────────────────────────────┐ │
│ │ [썸네일] 착장 이름   ●●● 스와치  │ │  ← MyGearItem (높이 72px)
│ ├──────────────────────────────────┤ │
│ │ [썸네일] 착장 이름   ●●● 스와치  │ │
│ └──────────────────────────────────┘ │
└──────────────────────────────────────┘
```

**주요 흐름**:
1. 시트 열림 → 내 장비 목록을 최근 사용 순으로 표시.
2. 내 장비 항목 탭 → 해당 착장 즉시 선택, 시트 닫힘, 기록 작성의 OutfitCard 갱신.
3. "새로 만들기" 탭 → 옵션 편집 화면(화면 3) 열림.
4. 내 장비 없음 → EmptyState(기본 캐릭터 + 안내 문구 + "새로 만들기") 표시.
5. 항목 길게 누름 or 더보기(···) → 편집/삭제 메뉴.

**컴포넌트**:
- `OutfitSheet` 바텀 시트: colors.canvas, rounded.2xl(상단), dim 오버레이, 패딩 24px
- `button-secondary` "새로 만들기": colors.subtle 채움, 잉크 라벨, rounded.lg
- `MyGearItem`: colors.subtle 채움, rounded.lg, 높이 72px, 좌측 캐릭터 썸네일 48×48 + 이름(body-lg) + 최근 사용일(caption-sm)
- 선택 상태: 2px 잉크 링

**예외 상태**:
- 내 장비 0개: EmptyState — 기본 착장 캐릭터 + "아직 저장된 착장이 없어요" + "새로 만들기" 버튼
- 내 장비 다수(스크롤 필요): 시트 최대 높이 화면의 75%, 내부 스크롤

### 3. 옵션 편집

**목적**: 캐릭터 미리보기를 보며 수영복·수모·수경의 실루엣·색·무늬를 30초 내에 설정하고 적용한다.

**레퍼런스 반영 포인트**:
- 차란 이미지 캐러셀 상단 고정: 캐릭터 미리보기를 최상단에 sticky 고정, 스크롤해도 유지.
- 차란 바텀 CTA: "적용" 버튼은 하단 고정, 엄지 존에 위치.
- 워크온 vs 달다방 스크롤 비교: 탭 전환 없이 세로 섹션 스크롤로 색·무늬·실루엣을 한 화면에서 처리.

**레이아웃** (전체 화면 390×844):
```
┌──────────────────────────────────────┐
│  ← 뒤로      옵션 편집               │  ← 네비게이션 바
│ ┌────────────────────────────────┐   │
│ │                                │   │
│ │    [캐릭터 미리보기 - sticky]  │   │  ← CharacterPreview (~40% 화면 높이)
│ │                                │   │
│ └────────────────────────────────┘   │
│  [수영복] [수모] [수경]              │  ← SlotTab (원형 토글 3개)
│ ─────────────────────────────────── │
│  실루엣                              │  ← 섹션 (ShapeChip 3종)
│  [●] [●] [●]                        │
│ ─────────────────────────────────── │
│  색 — 메인 | 포인트                  │  ← 세그먼트 전환
│  ● ● ● ● ● ●                        │  ← ColorSwatch 12개 (6×2)
│  ● ● ● ● ● ●                        │
│ ─────────────────────────────────── │
│  무늬                                │  ← PatternChip 5종 + 크기 세그먼트
│  [●] [●] [●] [●] [●]               │
│ ─────────────────────────────────── │
│ ○ 내 장비에 저장                     │  ← 토글 스위치
│ [         적용         ]            │  ← button-primary (하단 고정, 56px)
└──────────────────────────────────────┘
```

**주요 흐름**:
1. 진입 시 기존 착장 값으로 초기화 (새로 만들기면 기본값).
2. SlotTab으로 수영복 / 수모 / 수경 전환. 수모·수경 탭에는 착용 on/off 스위치 포함.
3. 옵션 변경 즉시 CharacterPreview에 반영 (150ms 이내).
4. "내 장비에 저장" 토글 on → "적용" 탭 시 내 장비에 저장 + Toast "내 장비에 저장했어요".
5. "내 장비에 저장" 토글 off → 이번 기록에만 사용.
6. 뒤로 탭 → 변경 사항 버림 확인 없이 이탈 (변경 중간 상태 저장 없음).

**컴포넌트**:
- `CharacterPreview`: sticky, 화면 높이 약 40%, 150ms 즉시 반영
- `SlotTab`: 원형 토글 3개 (수영복·수모·수경), 선택=잉크 채움, 비선택=subtle 채움
- `ShapeChip`: 56×56, 선택된 색 적용된 미리보기, 2px 잉크 링, 이름 caption-lg
- `ColorSwatch`: 지름 40px(터치 44px), 12색, 6×2 배열, 선택=2px 잉크 링+체크 아이콘
- 메인/포인트 세그먼트: 작은 세그먼트 컨트롤
- `PatternChip`: 56×56, 5종, 크기 3단계 세그먼트 컨트롤
- "내 장비에 저장" 토글: 기본 off
- `button-primary` "적용": 잉크 채움, 56px 높이, 하단 고정 (좌우 24px, 위 16px, 홈 인디케이터 34px)

**예외 상태**:
- 수모 off 상태: 수모 슬롯 색·무늬 선택 UI 비활성(disabled 처리), 미리보기에서 수모 미표시.
- 수경 off 상태: 동일.

### 4. 내 장비 목록 (마이 옷장)

**목적**: 저장된 착장을 관리(조회·편집·삭제)한다.

**레퍼런스 반영 포인트**:
- 워크온 탭 구조(항목 없음 처리): 빈 상태에서 목록 구조 대신 "새로 만들기" 단일 CTA만 노출.

**레이아웃** (전체 화면 390×844):
```
┌──────────────────────────────────────┐
│  ← 뒤로      내 장비                 │  ← 네비게이션 바
│                                      │
│ ┌──────────────────────────────────┐ │
│ │ [썸네일] 착장 이름   ●● 스와치  ⋯│ │  ← MyGearItem (높이 72px) + 더보기
│ ├──────────────────────────────────┤ │
│ │ [썸네일] 착장 이름   ●● 스와치  ⋯│ │
│ ├──────────────────────────────────┤ │
│ │ [썸네일] 착장 이름   ●● 스와치  ⋯│ │
│ └──────────────────────────────────┘ │
│                                      │
│                                      │
│ [    + 새로 만들기    ]              │  ← button-secondary 하단 고정
└──────────────────────────────────────┘
```

**주요 흐름**:
1. 내 장비 목록을 최근 사용 순으로 표시.
2. 항목 탭 → 옵션 편집 화면(화면 3)으로 이동 (편집 모드).
3. 더보기(···) 탭 → "편집" / "삭제" 메뉴.
4. "삭제" 탭 → 삭제 확인 Popup 표시.
5. 삭제 확인 Popup "확인" 탭 → 항목 삭제. 이미 저장된 기록의 착장은 변하지 않음.
6. "새로 만들기" 탭 → 옵션 편집 화면(화면 3, 새로 만들기 모드).

**컴포넌트**:
- `MyGearItem` 목록: 항목별 높이 72px, 우측 더보기(···) 아이콘
- 더보기 액션 시트: "편집" / "삭제" 2개 항목
- `Popup` (삭제 확인): 흰 면, rounded.xl, 폭 307px, 패딩 24px, "착장을 삭제할까요?" 제목(title-sm), "삭제 후 복구할 수 없어요" 설명(body-lg), 취소(secondary)/삭제(primary) 버튼 가로 배치
- `button-secondary` "새로 만들기": 하단 고정, 좌우 24px, 홈 인디케이터 34px

**예외 상태**:
- 내 장비 0개 (EmptyState): 기본 착장 캐릭터 중앙 + "아직 저장된 착장이 없어요" (body-lg, secondary) + "새로 만들기" button-primary
- 항목 1개 이상: 목록 + 하단 "새로 만들기" button-secondary

### 5. 기록 상세 캐릭터 카드

**목적**: 저장된 기록에서 그날의 착장을 확인한다. 읽기 전용이며 과거 착장은 변하지 않는다.

**레퍼런스 반영 포인트**:
- 카카오골프예약 헤더 + 스코어 구조: 날짜·수영장명 헤더가 맥락을 먼저 전달하고, 착장 카드가 그 아래에 이어지는 구조.
- 달다방 숫자 카드: 요약 지표(거리·시간) 옆 또는 아래에 착장 카드를 블록 단위로 배치.

**레이아웃** (기록 상세 화면 내 착장 섹션):
```
┌──────────────────────────────────────┐
│  2026.10.11 · 강남구 수영장          │  ← 날짜·수영장 헤더 (body-lg 700 / secondary)
│ ┌──────────────┐  ┌───────────────┐ │
│ │  거리: 1.5km │  │  시간: 45분   │ │  ← 요약 지표 카드 (기존 본체 컴포넌트)
│ └──────────────┘  └───────────────┘ │
│ ─────────────────────────────────── │
│  오늘의 물옷                         │  ← 섹션 라벨 (body-sm 700)
│ ┌────────────────────────────────┐   │
│ │                                │   │
│ │    [착장을 입은 캐릭터 카드]   │   │  ← OutfitCard (354×208, 읽기 전용)
│ │                                │   │
│ └────────────────────────────────┘   │
└──────────────────────────────────────┘
```

**주요 흐름**:
1. 기록 상세 화면 진입 → 날짜·수영장 헤더, 요약 지표(거리·시간), 착장 카드 순서로 표시.
2. OutfitCard는 탭해도 이동하지 않음 (읽기 전용).
3. 착장 카드에 저장된 착장 값(복사본)을 렌더링 — 내 장비 변경과 무관하게 그날 값 유지.

**컴포넌트**:
- 날짜·수영장 헤더: body-lg 700 (날짜) + body-sm secondary (수영장명), 상단 배치
- `OutfitCard` (읽기 전용): colors.subtle 채움, rounded.xl, 354×208, 탭 비활성
- "오늘의 물옷" 섹션 라벨: body-sm 700

**예외 상태**:
- 착장 미저장 기록: "오늘의 물옷" 섹션 자체를 노출하지 않음 (섹션 비노출 처리).

## 공통 규칙 요약

| 항목 | 규칙 |
|---|---|
| 필수 입력 | 착장은 선택 항목. 필수 표시(`*`) 및 저장 버튼 비활성 조건에 포함 금지 |
| 과거 기록 불변 | 기록 저장 시 착장 값을 복사해 저장. 내 장비 수정·삭제가 과거 기록에 영향 없음 |
| 자동 채움 | 기록 작성 진입 시 이전 기록의 착장을 기본값으로 표시 |
| CTA | 주요 버튼 잉크 채움, 보조 버튼 colors.subtle 채움. 브랜드 청록은 CTA에 사용 금지 |
| 선택 상태 | 2px 잉크 링 + 아이콘 (색에만 의존하지 않음) |
| 터치 영역 | 최소 44px (스와치 40px 지름이지만 터치 영역 44px 확보) |
| 그림자 | 팝업·바텀 시트에만 사용. 카드는 면 색(colors.subtle)으로 구분 |

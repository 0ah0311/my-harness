# SWIMMILE 오늘의 물옷 — 유저스토리 & 원칙

## 유저스토리

| # | 유저스토리 |
|---|---|
| 1 | 수영하는 사람이 기록 작성 화면에서 캐릭터를 눌러 수영복 착장을 프리셋 조합(실루엣·색·무늬)으로 설정한다. |
| 2 | 수영하는 사람이 다음 기록 작성 시 지난번 착장이 자동으로 채워져 있어 추가 입력 없이 저장한다. |
| 3 | 수영하는 사람이 새 수영복을 산 날 옵션 편집에서 색·무늬를 바꾸고 내 장비에 저장한다. |
| 4 | 수영하는 사람이 기록 상세 화면에서 그날의 착장을 입은 캐릭터 카드를 확인한다. |
| 5 | 수영하는 사람이 착장을 설정하지 않아도 기록을 저장한다. |

## 어기면 안 되는 것

| # | 원칙 | 근거 |
|---|---|---|
| 1 | **착장은 필수 입력이 아니다** — 저장하기 활성 조건에 포함하지 않는다. | 기록을 무겁게 하지 않는다 |
| 2 | **과거 기록의 착장은 절대 변하지 않는다** — 내 장비를 수정·삭제해도 이전 기록 캐릭터는 그대로다. | 그날의 착장 값을 복사해 저장 |
